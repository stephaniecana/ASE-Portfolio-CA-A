# Agentic Software Engineering Portfolio

## Course Introduction

This portfolio is created for CPELX330: focusing on Agentic Software Engineering and Responsible AI. The course introduces software engineering principles, AI agents, Agile methodologies, version control, and the ethical considerations involved in developing intelligent systems.

## Personal Learning Goals

1. Understand the fundamental principles of software engineering and intelligent agents.
2. Learn how AI agents make decisions and perform tasks independently.
3. Develop skills in using Git and GitHub to manage repositories, track changes, and maintain project versions.
4. Develop responsible AI applications that prioritize security, privacy, and ethical practices.
5. Strengthen my programming, problem-solving, and software development skills.

## Reflection from Part A

Through this activity, I learned that Agentic Software Engineering combines traditional software development with artificial intelligence to create systems capable of performing tasks and making decisions. I also understood that developing AI agents requires careful planning, continuous testing, and responsible implementation.

I also learned that Scrum supports continuous improvement through teamwork, inspection, and adaptation. Version control using Git is important because it helps developers manage changes and maintain a history of their work.

Most importantly, the NIST AI Risk Management Framework helped me understand that developing intelligent systems requires responsibility. AI agents should be designed with proper safeguards, risk management, and human oversight to ensure their safe and ethical use.
